# Real-Time Surplus Food Marketplace & Donation Tracker

Production-oriented full stack web application for connecting food businesses, consumers, and NGOs so surplus food can be sold at a discount or donated before it is wasted.

## Tech Stack

- Backend: Java 21, Spring Boot 3, Spring Security, JWT, Spring Data JPA, Hibernate, REST APIs, WebSocket, Maven, MySQL.
- Frontend: React, React Router, Axios, Material UI, Context API, Chart.js, Socket.io Client.
- Integrations: Cloudinary, Stripe Sandbox, Email notifications, Google Maps or OpenStreetMap.
